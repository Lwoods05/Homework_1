# LWS Creations

This static website is designed to work on GitHub Pages.

## How to publish on GitHub Pages

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to Settings → Pages.
4. Under Source, choose Deploy from a branch.
5. Select the main branch and the root folder `/`.
6. Save and wait for the site to publish.

The site uses relative links and local assets so it will load correctly from the published GitHub Pages URL.
